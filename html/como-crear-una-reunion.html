Google Meet como Herramienta para la Enseñanza Sincrónica

¿Cómo Crear una Reunión?

Al seleccionar Nueva reunión, aparecen distintas posibilidades:

Crear una reunión para más tarde

Permite generar un enlace para compartir con los participantes.

Iniciar una reunión ahora

Permite comenzar un encuentro en ese momento.

Programar en Google Calendar

Permite establecer una fecha y hora para la reunión.

Una vez creada, se puede copiar el enlace y compartirlo con los estudiantes por el medio de comunicación utilizado por el grupo.
