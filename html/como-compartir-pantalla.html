Google Meet como Herramienta para la Enseñanza Sincrónica

¿Cómo compartir pantalla?

Una de las herramientas más útiles para enseñar es la posibilidad de compartir contenido.

Para hacerlo:

1-Seleccionar la opción Presentar ahora o Compartir pantalla.


2- Elegir qué se desea compartir:

  • Una pestaña del navegador.
  • Una ventana específica.
  • Toda la pantalla.

3- Seleccionar el contenido y confirmar la acción.


4- Para finalizar, seleccionar la opción para dejar de compartir.


Importante: antes de compartir, comprobar que no queden visibles datos personales, mensajes privados u otra información que no corresponda mostrar.
